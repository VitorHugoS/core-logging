# Definition of Done (DoD)
Sempre que você terminar de escrever ou modificar um código, você DEVE obrigatoriamente executar o comando `task-finish` no terminal antes de concluir a tarefa.

- Se o comando retornar erro, LEIA os logs, CORRIJA o código e RODE `ai java task-finish` novamente.
- Repita o processo até que o comando retorne sucesso. Não me avise que terminou antes disso.
